# Miko-Spectrum<br>Міко-Спектрум
Information about the Ukrainian Sinclair ZX Spectrum clone.

## Box Information
The box has the following text:
- Програмна сумісність з розповсюджен комп'ютером "ZX Spectrum" (Software compatibility with the widely used ZX Spectrum computer.)
- Мова програмування БЕЙСИК (BASIC programming language)
- Підключення - в антенний вхід будь-якого телевізора. Колір - в системі PAL. (Connects to the antenna input of any television. Colour system: PAL.)
- Можливість підключення до входів: SCART, AUDIO-VIDEO, RGB (Connectivity to inputs: SCART, AUDIO-VIDEO, RGB)
- Автоматичний перехід у режим зчитування (Automatic tape loader activation)
- Підключення до трьох джойстиків одночасно (Simultaneous connection of three joysticks (Sinclair 1, Sinclair 2, Kempston))
- Гарантія 2 роки (Two year guarantee)

## Video Output
The video output connector is a Soviet-era, 12-pin РГ1Н-1-4 socket.  The corresponding plug is a РШ2Н-1-23.<br>

I'm currently not sure of the video output pins yet:
- pin 2 = ground
- pin 8 = enable for RGB output (must be grounded)
- pins 10/11/12 = RGB
