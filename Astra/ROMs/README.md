# Astra ROMs

## D6 (КС573РФ4Б)
The lower 8KB half of the Spectrum 16KB ROM.  It is identical to the 48KB Spectrum ROM apart from the boot screen text being changed to print "*** ACTPA ***".<br>
Cleverly, they are able to write the name "ASTRA" in Cyrillic but using the Latin font (no Cyrillic font available).<br>

## D7 (КС573РФ4Б)
The upper 8KB had of the Spectrum 16KB ROM.  This is identical to the 48KB Spectrum ROM apart from the character bitmaps which they have [modified 93 of the 96 characters](/Astra/Images/Astra_vs_ZX_font.png).<br>
